# Art Direction Template

> **Purpose:** Define the visual identity, artistic vision, and visual consistency principles of a game. This document establishes the direction that guides the creation, selection, production, and integration of visual assets.
>
> **Usage:** Copy this template into the game project's documentation directory and customize it for that project. Remove sections that are not relevant and add project-specific requirements where necessary.

## 1.1 Document Purpose

This document defines the artistic direction of **[Game Name]**.

It establishes the visual identity, artistic principles, visual references, color language, composition guidelines, asset requirements, and consistency rules that guide the game's visual development.

It serves as a reference for:

- User interface and visual effects.

- Animation standards.

## 9.1 General Consistency

All visual assets should follow the established art direction unless an intentional exception is documented.

Maintain consistency in:

- Color usage.
- Shape language.
- Proportions.
- Detail density.
- Materials.
- Lighting.
- Rendering style.
- Typography.
- Iconography.
- Visual effects.

## 9.2 Visual Hierarchy

Define how visual importance should be communicated.

Consider:

- Primary gameplay elements.
- Secondary gameplay elements.
- Environmental elements.
- Decorative elements.
- Interface information.
- Interactive elements.
- Warnings and critical feedback.

Visual deviations may be justified when they support gameplay, narrative, accessibility, or intentional artistic contrast.

| Technical Suitability | Does it meet technical constraints? |

## 11.3 Approval Process

AI-generated assets and externally sourced assets must also undergo human review before acceptance.

# 12. AI-Assisted Art Production

AI tools may support concept exploration, reference generation, visual prototyping, and asset production.

AI-generated output must follow these requirements:

1. Use this document as the authoritative visual direction reference.
2. Provide relevant project-specific visual requirements when generating assets.
3. Do not assume AI-generated output automatically matches the approved art direction.
4. Review generated assets for visual consistency, quality, and technical suitability.
5. Verify licensing, usage rights, and applicable tool restrictions.
6. Do not introduce major visual direction changes without project owner approval.
7. Preserve approved visual references and production decisions.
8. Do not use generated references as a replacement for actual asset specifications.

## 12.1 AI Art Generation Reference

When requesting AI-generated visual assets, include:

- Asset type and purpose.
- Relevant art direction principles.
- Visual style.
- Shape language.
- Color palette.
- Lighting and atmosphere.
- Composition.
- Required dimensions or aspect ratio.
- Technical constraints.
- Elements to include and avoid.
