# Reusable Game Development Documentation

This directory contains the shared knowledge base for all game projects.

## Documentation Categories

| Directory | Purpose |
|---|---|
| 00_studio_standards | Studio-wide rules and conventions |
| 01_game_design_guidelines | Reusable game design knowledge |
| 02_technical_standards | Engineering and Godot standards |
| 03_art_audio_standards | Art and audio production standards |
| 04_production_standards | Project and production workflows |
| 05_qa_standards | Quality assurance standards |
| 06_templates | Reusable documentation templates |
| 07_agent_workflows | Repeatable AI agent workflows |

## Usage

- Studio standards should be followed by all projects.
- Guidelines should be applied when relevant to the game.
- Templates should be instantiated inside individual game projects.
- Agent workflows should be used when performing the corresponding tasks.

## Principles

1. Avoid duplicating shared documentation across projects.
2. Keep game-specific decisions inside their respective project.
3. Update shared standards deliberately and consistently.
4. Do not treat placeholder documents as approved standards.
