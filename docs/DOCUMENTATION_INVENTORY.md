
# Documentation Inventory

## 1. Purpose

This document provides an authoritative inventory of documentation currently maintained in this repository.

It records each document's location, purpose, category, status, and relevant dependencies.

This inventory is a registry, not a roadmap or a list of planned documents.

Only documents that physically exist in the repository should be listed.

## 2. Status Definitions

| Status | Description |
|---|---|
| Draft | Document exists but has not been formally reviewed. |
| In Review | Document is undergoing review. |
| Approved | Document has been reviewed and accepted. |
| Deprecated | Document is retained for reference but should no longer be followed. |
